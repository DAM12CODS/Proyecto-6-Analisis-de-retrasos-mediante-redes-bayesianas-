# Proyecto-6-An-lisis-de-retrasos-mediante-redes-bayesianas-
Una empresa necesita estimar la probabilidad de retraso de sus entregas y analizar sus  posibles causas. Dispone de información sobre factores como tráfico, clima, preparación  del pedido y estado del vehículo.  Desarrollar un sistema que permita responder consultas antes de realizar una entrega y  después de conocer su resultado.
